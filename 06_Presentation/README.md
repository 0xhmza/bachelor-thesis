# Presentation

One Beamer source, `slides.tex`, used for both talks. Build it with
`.\build.ps1 slides`, or open it in TeXstudio and press F5.

## The two talks

| Talk | When | Roughly |
|---|---|---|
| Proposal talk | After the proposal is approved | Problem, gap, RQ, method, timeline |
| Defence / colloquium | After submission | The same arc plus results and what they mean |

Keep them in one file and comment out what the current talk does not need, so the
two versions cannot drift apart. If they genuinely diverge later, split into
`slides_proposal.tex` and `slides_defence.tex` — not before.

## Rules

- **Bibliography:** `../03_Thesis/references.bib`, like every other document here.
  Never add a second `.bib`.
- **Figures:** `figures/`, generated by the scripts in `05_Data/analysis/`.
  Do not hand-edit a figure you will need to regenerate.
- **Before presenting:** `grep -n "todo{" slides.tex` must return nothing.
