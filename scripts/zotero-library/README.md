# Zotero library file

`03_Thesis/references-zotero.rdf` is a Zotero RDF file with one Zotero item per entry of
`03_Thesis/references.bib` (100 entries), generated by `v001/build_zotero_library.py`.
Never edit it by hand. It is the only generated copy of the bibliography: `references.bib`
stays the single source.

## Regenerate (every time `references.bib` changes)

```
python scripts/zotero-library/v001/build_zotero_library.py
python scripts/zotero-library/v001/build_zotero_library.py --check   # exit 1 if out of date
```

Compile the thesis first (pdflatex, bibtex, pdflatex, pdflatex): the reference numbers come from
`03_Thesis/thesis.bbl` and the script refuses a `.bbl` that does not match `thesis.aux`. Numbers also move
when citations in the thesis change, so regenerate after such edits too. `python scripts/check_project.py`
warns when the file was built from another `references.bib`.

## What an item holds

| Zotero field | Source |
|---|---|
| Item type, title, creators (authors, editors, organisations), date, DOI, URL, access date, pages, volume, issue, publisher, place, series, edition, ISBN, venue | the `.bib` entry, mapped to the Zotero field of the same meaning |
| Citation Key | the BibTeX key |
| **Rights** and **Call Number** | the reference number as printed in the thesis, `[40]` (Call Number only where the item type has it; web pages do not) |
| Extra | BibTeX fields with no Zotero field (`note`, `addendum`, `howpublished`, `organization`, …), the catalogue id, reading status, priority, topic, the keywords printed on the PDF's title page, and the linked file path |
| Abstract | `literature-index.json`, else the PDF's title page; automatic extraction, so it can carry trailing front matter |
| Tags | `thesis:cited` or `thesis:uncited`, `status:…`, `topic:…`, `priority:…` (from the literature catalogue) |
| Child note | the `%` comment block above the entry in `references.bib` (provenance, checks) |
| Linked file | every PDF of `01_Literature/library/` that belongs to the entry (matched by author, year and title words; exceptions in `v001/pdf_overrides.csv`), as a **relative path** from `03_Thesis/`; the PDFs are never copied |

Entries without a PDF in the library are in the file without an attachment. Entries the thesis does not cite have
no number, the tag `thesis:uncited` and the Extra line `Thesis reference: not cited in the thesis`.

## Import into Zotero

1. Zotero: **Edit ▸ Settings ▸ Advanced ▸ Files and Folders ▸ Linked Attachment Base Directory ▸ Choose…** and pick the project
   folder (the one that contains `01_Literature/`). Do this once per device, before importing. Zotero then stores
   the links as `attachments:01_Literature/library/…`, which resolve on every device that sets its base directory to the
   project folder on that device (the folder may sit at a different place on each).
2. **File ▸ Import… ▸ A file ▸** `03_Thesis/references-zotero.rdf`; choose **Link to files in original location** (not
   *Copy files to the Zotero storage folder*, which would duplicate the PDFs). Keep *Place imported collections and
   items into new collection* ticked.
3. Right-click the column header ▸ tick **Rights** (or **Call Number**) and click it to sort: `[1]`, `[2]`, … `[94]`
   sort as numbers, and works without a number come last.
4. Double-click an item: Zotero opens its PDF. Find a reference by typing `[40]` in the search field (mode *All Fields &
   Tags*) or by sorting the column.

Importing again adds the items a second time (Zotero does not merge). Import into a new library or collection and
delete the old one, or use *Duplicate Items*.

## Tests

```
python -m unittest discover -s scripts/zotero-library/v001/tests
python scripts/zotero-library/v001/verify/verify_in_zotero.py --base-dir
```

The second command starts the installed Zotero with a throwaway profile and data folder (the real library is not
touched), imports the file as *File ▸ Import* does and compares every item with `references.bib`: fields, creators,
reference numbers, tags, notes and linked files (present on disk, stored relative to the base directory).
