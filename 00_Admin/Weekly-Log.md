# Weekly log

One entry per week, newest first. Five lines are enough; the point is a record the
supervisor can skim before a meeting and that the thesis timeline can be checked
against. Review the [risk register](Risk-Register.md) while writing it.

## Template

```markdown
## Week of YYYY-MM-DD
- **Done:** …
- **Decisions moved:** Dnn open → proposed (…)
- **Reading:** n works read (see 01_Literature/reading-status.csv)
- **Blocked by / need from supervisor:** …
- **Next week:** …
```
