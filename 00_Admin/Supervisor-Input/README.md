# Supervisor Input

Material sent by the advisor outside of a meeting. One pair of files per input,
named `YYYY-MM-DD_Supervisor-Input.*` by the date it was received:

- the original PDF/attachment, unmodified
- a `.md` transcription, reorganised into reading list → gap → RQ → scope →
  action items, so it can be searched and linked from the proposal

Things said *in* a meeting belong in `../Meeting-Notes/` instead.
